# Guia do Usuario - IFF Pesquisas

Este guia descreve os principais fluxos de uso do IFF Pesquisas em linguagem objetiva, voltada a estudantes, orientadores e avaliadores do projeto academico.

## 1. Explorar pesquisas

1. Acesse a pagina inicial.
2. Entre em **Explorar pesquisas**.
3. Use a busca por titulo, resumo ou palavras-chave.
4. Se necessario, filtre por area de conhecimento, autor ou orientador.
5. Abra uma pesquisa para ver detalhes, orientador, autor, area e arquivos disponiveis.

## 2. Publicar uma pesquisa

1. Acesse sua conta institucional.
2. Selecione **Publicar pesquisa**.
3. Preencha titulo, resumo, area de conhecimento e orientador.
4. Adicione palavras-chave para facilitar a busca.
5. Inclua PDF e imagem de capa quando estiverem disponiveis.
6. Revise as informacoes e envie.

## 3. Editar, despublicar ou excluir uma pesquisa

1. Acesse **Minhas publicacoes**.
2. Use **Ver** para conferir a publicacao.
3. Use **Editar** para corrigir dados.
4. Use **Despublicar** para retirar a pesquisa do feed publico sem excluir.
5. Use **Excluir** apenas quando tiver certeza; o sistema solicita confirmacao.

## 4. Solicitar colaboracao entre cursos

1. Acesse **Colaboracoes**.
2. Selecione **Nova solicitacao**.
3. Descreva o projeto e o tipo de apoio necessario.
4. Selecione os cursos desejados.
5. Informe area de conhecimento, urgencia, orientador e competencias necessarias.
6. Publique a solicitacao.

## 5. Demonstrar interesse

1. Abra uma solicitacao de colaboracao.
2. Leia a descricao, cursos desejados e competencias necessarias.
3. Se estiver autenticado, selecione **Tenho interesse**.
4. O autor vera seu nome na lista de interessados.
5. Caso mude de ideia, remova o interesse pela mesma tela.

## 6. Chat do Projeto

Ao demonstrar interesse em uma colaboração, o chat do projeto é criado automaticamente (ou você é adicionado a ele). 

1. Acesse a aba **Mensagens** no menu principal.
2. Selecione o projeto na lista lateral.
3. Você pode conversar com o autor e com outros interessados.
4. O chat é exclusivo para os participantes da colaboração.
5. Se você remover seu interesse, sairá do chat, mas o histórico é mantido.

*Mensagens diretas avulsas entre usuários fora de projetos ou matchmaking automático não fazem parte desta versão.*

## 7. Arquivos aceitos

- Pesquisa: PDF para o trabalho academico e imagem de capa quando aplicavel.
- Solicitacao de colaboracao: imagem ilustrativa em JPG, PNG ou WebP, com ate 5 MB.

## 8. Boas praticas

- Use titulos claros e objetivos.
- Informe o orientador corretamente.
- Evite descricoes vagas.
- Escolha cursos desejados que tenham relacao real com a demanda.
- Revise os dados antes de publicar.
- Use filtros ativos para entender por que certos resultados aparecem ou deixam de aparecer.

## 9. Recursos de acessibilidade e eficiencia

- A busca pode ser acessada rapidamente com `Ctrl+K` ou `Cmd+K`.
- Campos obrigatorios indicam mensagens de erro claras.
- O sistema informa carregamentos, publicacoes, exclusoes e alteracoes de status.
- Acoes destrutivas exigem confirmacao.

## 10. Observacao para avaliacao academica

A adequacao as Heuristicas de Nielsen foi finalizada como **Aprovado com ressalvas**. Isso significa que os fluxos principais foram melhorados e documentados, mas algumas evolucoes permanecem registradas como trabalhos futuros.
